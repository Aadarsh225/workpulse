# ✨ Overview

WorkPulse is a modern AI-powered productivity and workflow management platform designed to help users organize tasks, track goals, manage projects, and improve productivity through intelligent AI assistance.

The application combines a responsive frontend experience with a scalable backend architecture and persistent authentication system to deliver a production-ready workflow management solution.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Aadarsh225/workpulse.git
```

Move into the project directory:

```bash
cd workpulse
```

Install dependencies:

```bash
npm install
```

---

# 🔑 Environment Variables

Create a `.env.local` file in the root directory and add:

```env
GEMINI_API_KEY=your_gemini_api_key_here
APP_URL=http://localhost:3000
```

Get your Gemini API key from:

https://aistudio.google.com/app/apikey

---

# ▶️ Run Locally

Start the development server:

```bash
npm run dev
```

The application will run on:

```bash
http://localhost:3000
```

---

# 🏗 Build for Production

Build the frontend and backend:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
